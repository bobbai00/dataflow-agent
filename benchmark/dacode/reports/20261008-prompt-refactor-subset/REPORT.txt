Six reviewed mechanisms and limitations:

- Wrangling: native configurations read the actual YAML target layout and
  melt/split the complete Ebola data. Smolagents loaded YAML inside a
  generic program, guessed rename/cast rules, and exported unchanged wide
  data. Conditional inspection of an unfamiliar target schema was useful.
- Manipulation: all configurations missed aggregation across repeated
  product names. There are 321 product IDs and 291 names. Reaggregating
  SKU-pair counts by named pairs reproduces the reference counts 35/34.
  Native11 attached names after counting and selected top pairs too early.
- Insight: Native01 cast seven valid comma-formatted densities to null,
  mean-imputed them, and selected Palestinian National Authority instead
  of Monaco. Flow captions explicitly reported seven conversion failures.
  Relevant telemetry was available and ignored.
- Plotting: native runs recovered from real engine file-I/O restrictions.
  Explicit open(...).write(...) is rejected in Python UDFs; supported CSV,
  savefig, and capture routes work. Native10 omitted writing analysis.py
  after that error. The official image metric checks the image and actual
  figure metadata, not the updated analysis.py file.
- Statistics: the request and README omit the FIFA-only/since-2002 scope
  used by the published p-value 0.0051066. Full-data tests in these runs
  give p-values near zero; the unchanged metric's absolute 0.01 tolerance
  accepts them. Supplementary complete-record checks flag the differing
  p-values. Treat this as source/method ambiguity and metric tolerance,
  rather than clear evidence of wrong answers or exact reproduction.
- Regression: supplied engineered columns Total_Animals and
  Biogas_per_Animal multiply to all 74 reference targets to about 1e-10.
  Native validates and applies that relationship; smolagents fits tree
  estimators. This measures source interpretation and export more strongly
  than difficult predictive ML fitting.

All classification outputs have normalized F1 score 0.955923, corresponding
to raw F1 about 0.982369. Clustering uses silhouette on submitted processed

Comparison protocol:

All arms use Luna gpt-5.6-luna at medium reasoning effort, the same original
task text and input bytes, 25 steps, an 8,192-token completion ceiling,
5,000-character full-result/print caps, and a 900-second deadline. Native
sampling and each evidence kind have separate 2,000-character budgets.
Profiles are collected identically in all native arms. Explicit session
views are sample/full without data stats and sample_stats/full with them.

The native system prompt includes SINGLE_TASK_ANALYSIS_PRINCIPLES once.
Smolagents 1.23.0 receives that exact text via CodeAgent instructions= and
uses its built-in structured-output protocol plus stock LocalPythonExecutor
in a credential-free, isolated worker. Local execution/context mechanics
and step units differ. Native workers retain network access for the engine;
smolagents Python has no network. Model-written code cannot read gold,
reports, credentials, or repository history through its mounted task data.

The upstream DA-Code revision is b211daf51fdc9b52d5087c9df28ac50191bcabed.
Official CSV, text, image, and ML functions/options are unchanged. CSV

All 32 native wire groups and eight smol provider traces reconcile token

They retain content hashes and numeric results without raw conversations,
