environment-hard-18: the script wrapper lost final_answer(True) to recursive memory serialization. The saved empty response was graded 0 by the unchanged evaluator; no model rerun or answer replacement.

Concrete trace comparisons
- legal-easy-26: Both answered the six-state identity-theft question correctly. Script call 2 emitted 128,000 tokens with 2,319 literal pseudo-tool calls; parsing failed, later calls recovered. Dataflows previewed, updated parsing, built Map/Window/Filter and repaired null handling. The cost win here is protocol robustness; it does not isolate a stats effect.
- archeology-easy-6: Both identified Sao Paulo among cities with negative latitude and longitude. Script loaded/filter/sorted in one code block, then answered (2 responses). Dataflows retrieved sample_stats, built Filter/Sort/Limit, retrieved 5 full rows and needed an Answer correction (4 responses). Smaller prompt and shorter output also favored script.
- environment-hard-7: Both derived 312/2063 and 140/3295 marine exceedance rates. Dataflow flow evidence correctly exposed 1,373 unmatched samples and the agent investigated them. Script submitted 10.87 percentage points; Dataflows submitted the equivalent proportion 0.11, which fails the required benchmark units.
- archeology-hard-7: Both computed 274 cities under Euclidean degree distance and 295 under an axis-aligned box. Script chose Euclidean, matching the original reference; Dataflows chose the box. Dataflows recovered an invalid cross-join edit and accurately reported the 5,873*1,388=8,151,724-row cross product. This is interpretation, not inaccurate flow counters.
- environment-easy-2: Dataflows correctly listed all 8 years in its first plain-text conclusion, but after Answer correction submitted only an incomplete sentence ending with violations (. Its saved answer therefore fails. Script submitted the list through final_answer. The trace confirms a submission failure; raw provider arguments are unavailable, so the model/proxy source of truncation is unresolved.
- biomedical-hard-3: Dataflows explored Excel sheets with previews and sample_stats, sorted APP_Z_score, joined the selected sample to metadata and retrieved one full 212-column row to see the hidden Age field (60). Script received no provider response before its 1,200-second deadline. The full retrieve was justified; the accuracy difference is a timeout, not proof that stats improved reasoning.
- environment-hard-18: Script internally executed final_answer(True), but smolagents memory serialization raised RecursionError and the wrapper saved No response from agent. Optional full-memory export then blocked grading. That unchanged saved answer was graded 0 with the original evaluator. Dataflows submitted True and passed. This is a framework failure, not analytical evidence for stats.

Limits
- One attempt per task per system; no best-of or recovery model runs.
- Original mean scores include partial RAE/F1 credit; exact passes require score>=1.
- Costs are recorded successful-response costs at frozen rates, with cache discounts; evaluator and engine costs excluded.
- SDK retries and deadline requests may have unreported provider charges. Recorded zero at deadline does not mean free. Earlier jobs lack HTTP retry hooks.
- Frameworks and prompts differ: guided 5K script preview vs adaptive 2K dataflow samples, separate 2K stats/flow budgets and bounded 100K full reads. This comparison cannot attribute a score/cost difference solely to stats or flow.
- Independent checks cover retained complete tables and six selected sources (including the recorded profile prefix), not every row of every source. Profile budgets omit some value-frequency facts.
- Four Dataflow tasks ended without an Answer action; additional submitted-answer errors are included in original grades.
