Changes on state-registry that deserve separate integration work

- Wide-table evidence: 4870f9b70 and fd0e5d031 raise profiling to 400 columns,
  a 512 KiB per-worker payload, 1 MiB result transport, and a 1-second time
  budget. The Python collector, Scala transport and TypeScript decoder change
  together. Prefix evidence can prove an observed value exists in that prefix;
  it does not establish whole-table counts or absence. This branch still uses
  the recorded 128-column/64 KiB/0.2-second limits with explicit coverage.
  Increasing them would change the experimental treatment and needs a separate
  matched pilot, especially on wide survey tables.
- Pandas semantics (8bdf0d5bd) include default NA tokens, duplicate-header
  renaming, null-group handling and preserved row labels. These change table
  contents and operator contracts, so copying the runtime alone would make
  our current prompts, schema and evidence disagree. Port with coordinated
  tests and a fresh benchmark cohort.
- The function/definition registry and LongDS task entries address reusable
  analyses and historical results. They are a broader design than our explicit
  graph action interface. Its repair review gives an important counterexample:
  correcting a duplicated calculation downstream leaves the upstream copy
  wrong even with perfectly fresh engine results. Preserve shared definitions
  and fine-grained graph dependencies when applying semantic repairs.
- The recent Answer guidance (815cd6f75) makes each requested conclusion
  explicit. Our prompt keeps the requested answer format and now explicitly
  places it inside answer.content, which is also needed for Sonnet 5.5.

Implemented interface fixes

The dataflow action envelope remains strict locally. A LiteLLM callback
preserves provider-side strictness on supported Claude aliases while moving
unsupported bounds and costly regexes into descriptions. The live Haiku
schema first failed with "Schema is too complex"; removing repeated regex
constraints made the same action union work. Local AJV still checks those
constraints, including string types and array bounds. No malformed JSON is
silently decoded or repaired.

Explicit project None defaults now match omission. Sample-statistics views
label incomplete records separately from statistics coverage. The prompt
explains full-coverage exhaustive nonnull values without inferring row order
or cross-column pairs. It retains the native-operator and one-operation-per-
operator principles, explains returned tables versus print output, and
reserves Answer. Remaining-budget notices are immutable context events at
three and one calls left; they do not change earlier cache prefixes or add
model calls to the original budget.

Sonnet 5.5 requires automatic tool choice; native mode still validates the
final Answer contract. The initial task pilot found a correct plain-text No
that failed that contract. A follow-up strengthens the prompt and adds a
concrete Answer envelope to the single bounded protocol correction. Both
original observations and failed first-attempt results are retained. The
campaign audit now flags text-only replies and missing Answer actions.
