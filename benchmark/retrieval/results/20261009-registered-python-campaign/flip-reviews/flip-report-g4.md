The spec line came back in that same observation, and in call 3 the model answered without reconciling it.
Evidence at hinge:
- Flow arm, call 2 observation (same call as the code): `| 166 | 50       I4   999      ap-index                     nT |`. Top of the lag table: `| 6 | 0.110741039647047 | -0.332777763149894 | 130 |`, with every r² ≤ 0.11 and nearly all correlations negative.

- None arm: call 3 retrieved `| 166 | 50 I4 999 ap-index nT |` before any parsing. Call 4 then wrote `value=float(p[49])` and got `| 24 | 0.763746694035202 | 125 |`.
Why: This was a memory-recall error about the field position, made in a call that batched the spec lookup with the computation. The flow content at the hinge was boilerplate and said nothing about columns. The stats arm, which has no flow lines, batched the same way and also guessed wrong (`ap=float(fields[42])`, a proton-flux fill column). Its guess failed loudly (null r²), so it diagnosed and corrected to field 50. The both arm, which had flow lines, looked up the spec first and used `p[49]`. Pattern: only the flow arm failed (none, stats, both and smolagents passed).

Across these 11 flips (6 losses, 5 gains), flow content changed one decision and caught no errors. Six flips came down to silent parse or selection errors inside custom Python functions: the AE column read as ap, the first Enterococcus column only, the comma-less regex, the en-dash name keys, the state regex, and the footnote row counted as a metro. Across a custom-Python boundary the flow lines reduce to "input rows=[...], output=N; row/column mapping unknown", so the knob had nothing to say exactly where these runs went wrong. The one data-bearing line that mattered was the scan header hint in environment-hard-12. It was accurate for the files it named, but the flow arm copied its 6-column header to every file and skipped the raw-layout check the none arm ran. The both arm got the same hint and previewed the un-hinted files, so the effect is a route the hint made available, not misleading content. Built-in flow lines near a hinge only restated counts or confirmed choices already made: "row denominator=15/15" in biomedical-hard-7, and "Filter kept=48/52" in legal-hard-16, which arrived after the decisive loader. No flip involved the call cap or timeout; the flow arms used 3–7 calls. In three losses the flow arm skipped a check the none arm ran (the ap spec lookup before parsing, the raw layout dump, the unmatched-metro audit), and only in environment-hard-12 did flow content plausibly stand in for that check. None of the five gains traces to flow content: two are answer-format or judge artifacts, and three are parsing or interpretation choices made before any data-bearing flow line existed. The 6–5 balance is consistent with run-to-run variance, and the knob's only causal footprint here is the one KNOB-ROUTE loss.
