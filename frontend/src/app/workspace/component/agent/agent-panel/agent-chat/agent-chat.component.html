Snapshot-selection policy for the ReAct context. Latest: events + one trailing snapshot of the current state (cheapest). Delta: each turn followed by a snapshot that renders changed operators in full and unchanged ones as id+description placeholders.
When enabled, the model may emit multiple tool calls in one assistant turn — the agent serializes them in topological order so an operator that depends on a sibling created in the same turn waits for its upstream. When disabled, the provider emits one tool call per turn.
When enabled, results the agent observes carry bounded column and table facts — null and distinct counts, ranges, top values — so the model can reason about column semantics without issuing inspection operators. In native mode, the statistics shown with a result also follow the result view the agent requests.
When enabled, results the agent observes also carry version-matched input/output facts — rows kept, keys matched — that tie each output to its inputs.
